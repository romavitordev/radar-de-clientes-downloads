# Radar de Clientes — downloads

Instaladores do **Radar de Clientes** para Windows, usados pela atualização
automática do app. Este repositório não tem código-fonte.

O programa só funciona com uma licença válida. Cada versão publicada aqui é
conferida pelo app com uma assinatura digital antes de ser instalada.

Para comprar ou baixar pela primeira vez, use a área de membros da compra.
